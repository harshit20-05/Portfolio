## ⚡ Tech Stack & Architecture
* **Frontend**: HTML5, Modern CSS3 (CSS Variables, Flexbox/Grid, Glassmorphism, Theme Engine), Vanilla ES6+ JavaScript
* **Interactivity**: Project category filtering, animated metrics counters, IntersectionObserver scroll reveals, certificate modal lightbox, theme persistence via `localStorage`
* **Integrations**: GitHub Activity Calendar API with graceful offline fallback, Formspree contact form endpoint

## 💻 Local Preview
To preview locally:
```bash
# Clone the repository
git clone https://github.com/harshit20-05/Portfolio.git
cd Portfolio

# Start a simple HTTP server (Python 3)
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
